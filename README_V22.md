# Hex Unified Research Lab V22 — Persistent Native Research Queue

V22 builds on V21.1 (responsive tabs) and retains the V21 native research workflow.

## New interface

`http://127.0.0.1:8141/queue-v22`

1. Pause the engine.
2. Select up to 16 cells, 1–20 steps per run, and 1–100 repetitions.
3. Queue the job and monitor progress. Reports are generated by the existing V21 workflow.
4. Job records persist at `research_data/v22/jobs/*.json`.

## Recovery and cancellation

Queued jobs resume when the server restarts. Jobs marked `running` at shutdown become `interrupted` and **require manual retry**, preventing silent duplicate execution. Cancellation is checked between runs. Running jobs can finish the current bounded experiment before cancellation.

The worker requires the local server to stay alive; it is not an Android background service. Jobs use the V21 `/api/v21/execute` implementation, including its pause requirement, snapshot limitations, and report generation. A failed job is retained with an error. Only one queued job runs at a time.

## Termux

Install `python clang unzip`, extract the ZIP, then `cd v7work && sh start_unified.sh`.
