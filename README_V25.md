# Hex Unified Research Lab V25 — Adaptive Mathematical Research

V25 adds `/adaptive-v25`, a strategy comparison and follow-up queue interface on top of V24.4.

- Uses actual saved playback records to calculate per-recording predicate pass fractions.
- Ranks four candidate tests by between-recording disagreement and mixed outcomes.
- Requires user approval before submitting a targeted experiment to the existing V22 queue.
- Reuses V23.1 cycle creation and V23.2 evidence linkage for subsequent evaluation.
- Does not claim proof, statistically calibrated confidence, automatic causal identification, or autonomous scientific discovery.

Start with `sh start_unified.sh` from the `v7work` directory. Open `/adaptive-v25` on the active server port.
Save at least one native playback recording before analyzing or submitting follow-ups.
