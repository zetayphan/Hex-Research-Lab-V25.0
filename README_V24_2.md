# V24.2 — Broader hypothesis follow-ups

The V23.1 research-cycle route now uses V24 discovery evidence and no longer requires every stage output to equal its input. A saved playback recording with at least one valid input/output pair is required. A cell-preservation hypothesis may be queued even when contradicted by the discovery data. Follow-up evidence is evaluated against the chosen predicate, with counterexamples reported.

This update preserves the V24.1 queue fixes and existing routes. Queue jobs remain bounded and require the server to run. New installations do not automatically inherit research_data from older folders.
